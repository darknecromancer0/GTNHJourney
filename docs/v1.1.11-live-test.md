# GTNH Journey v1.1.11 live test

Target: GTNH 2.9.0-beta-2 / NEI 2.8.111-GTNH.

## Industrial Diamond exact-identity regression

1. Start a world with both `minecraft:diamond` and `IC2:itemPartIndustrialDiamond` already researched, or legitimately obtain both so Journey researches them.
2. Enable the Journey researched panel (`J`). Confirm ordinary Diamond and Industrial Diamond are both visible as separate entries. Industrial Diamond must not be hidden inside NEI's collapsible diamond group.
3. Hover both entries. Each must show `Journey: Researched`, and the Industrial Diamond entry must still be the IndustrialCraft 2 item.
4. Retrieve one Industrial Diamond from Journey. Open a recipe that specifically requires Industrial Diamond and verify the retrieved stack is accepted as that recipe ingredient.
5. Retrieve an ordinary `minecraft:diamond` separately and confirm it remains the ordinary Diamond rather than being substituted for the IC2 item.
6. Disable Journey mode and confirm normal NEI collapsible-item behavior still works unchanged.
7. Restart the client/world. Repeat steps 2 through 5 and verify both exact researched identities persist after restart.

Expected result: Journey preserves `minecraft:diamond` and `IC2:itemPartIndustrialDiamond` as distinct researched/retrievable states while Journey owns the NEI panel, without changing normal NEI grouping outside Journey mode.
