# GTNH Journey 1.1.24 Live Regression Checklist

Target: GT New Horizons 2.9.0-beta-2, NEI 2.8.111-GTNH.

Use a disposable copy of the world for destructive power-network tests.

## J / N / F / C click contract

- Open **J** and hover a researched 64-stack item.
  - LMB gives exactly 1 item.
  - RMB gives one natural stack.
  - Shift+RMB fills available main-inventory slots with natural stacks.
  - Alt+LMB adds the exact state to F and does **not** issue an item on that click.
  - Repeating Alt+LMB does not remove it from F.
  - Alt+RMB is not a favourite gesture here; ordinary RMB issuance still works.
- Repeat the same checks in **N**. Alt+LMB adds to F, including exact NBT/meta variants.
- Open **F**.
  - LMB/RMB/Shift+RMB have the same issuance semantics as J/N.
  - Alt+RMB removes the exact state from F and does **not** issue an item on that click.
  - Alt+LMB is not a favourite gesture here; ordinary LMB issuance still works.
- Open **C**.
  - LMB gives 1, RMB gives a natural stack, Shift+RMB fills available main-inventory slots.
  - Alt does not add/remove F entries from C.
- Verify Item Subsets, text search, native ordering and page preservation still work in J/N/F/C.

## Machine speed safety

- `/journey speed machines 1`, `2`, `4`, `8`, `16` must apply normally.
- At 16x, run an EBF from a real GT power chain containing batteries/buffers/cables. Confirm recipe progress and EU-network activity advance together without a Journey-created partial-pass overload.
- `/journey speed machines 32`, `64`, and `128` must be rejected with a red unsafe-command error before the multiplier changes.
- Shorthand `/journey speed 32` must also be rejected because shorthand selects MACHINES.
- Tab completion after `/journey speed machines ` must stop at 16.
- `/journey speed world 32`, `64`, and `128` remain available when the server tick-rate adapter supports them. Verify the complete world advances rather than only TileEntities.
- After an unsafe rejected command, `/journey speed status` must still show the previously active safe state.

## External Journey snapshot recovery

- Let the world pass an automatic Journey snapshot cadence with a non-empty researched list and a research-state change.
- Confirm an external snapshot exists under:
  - `<instance>/gtnhjourney-recovery/<world>/research-snapshots/`
  - It must be outside `<instance>/saves/<world>/`.
- Research several unmistakable items, allow a newer external snapshot to be written, then restore an older Minecraft world backup.
- Before recovery, note the current player inventory and Journey list.
- Run `/journey snapshot latest return`.
  - Journey research list must match the newest valid external snapshot for this world/player.
  - The player's current inventory must remain unchanged.
  - J/N views must refresh immediately after the command.
- Optional corruption test: copy the external recovery folder, corrupt the newest `.dat`, then run the command. It must skip the corrupt file and use the next newest valid snapshot instead of failing the whole archive.
- Run the command again without changing Journey. It should report that the latest snapshot already matches.

## Command error behaviour

- Unknown root, for example `/journey wat`, must show one vanilla-style red error with valid top-level Journey choices. It must not dump the full help page.
- `/journey explosions ogf` must show a red scoped error suggesting only the valid `explosions` branch choices.
- `/journey explosions machines wat` must show a red scoped error suggesting `status|on|off`.
- `/journey snapshot latest wat` must show a red scoped error suggesting `return`.
- Valid commands and Tab completion must still work after an error.

## 1.1.24 regression sweep

- F favourites persist across save/reload and synchronize after reconnect.
- General `/journey undo [n]` and `/journey redo [n]` still merge research/admin history correctly.
- Favourite add/remove, speed and explosion changes remain reversible through their action journal.
- `/journey explosions machines on|off|status` still controls the GregTech machine-explosion switch without partially changing the global setting on failure.
- keepInventory death watchdog still detects missing main/armor/Baubles contents and `/journey return death inventory` restores only missing content non-destructively.
- Debug Researcher Tool changes mode once per physical Shift+RMB press.
- Mob spawners researched by BLOCK/AREA_16 retain the exact registered entity metadata and never fall back to pig meta.
- JAR metadata, runtime `GTNHJourney.VERSION`, `mcmod.info`, and Gradle project version all report `1.1.24`.
