# GTNH Journey 1.1.9 live test

This pass verifies the split between machine-only acceleration and complete world acceleration.

## Machines mode

1. Run `/journey speed machines 16`.
2. Observe a GregTech machine and a Botania flower/pool setup that normally changes over time.
3. Observe sun/moon movement, mobs and normal world behavior at the same time.
4. Repeat at 32x, 64x and 128x.

Expected:

- loaded tickable TileEntities accelerate best-effort;
- GregTech machines and Botania tile-based production receive extra updates;
- day/night, mobs, weather and random world ticks remain at normal server speed;
- heavy worlds may achieve less than the requested machine multiplier because extra work is capped to avoid long server stalls.

## World mode

1. Run `/journey speed world 16`.
2. Confirm machines, Botania, day/night, mobs and other normal server-tick behavior all accelerate together.
3. Repeat at 32x, 64x and 128x.

Expected:

- complete `MinecraftServer.tick()` acceleration remains active;
- high-speed overrun protection prevents an unbounded catch-up backlog;
- actual achieved speed remains limited by CPU capacity.

## Status and reset

- `/journey speed status` reports `MACHINES` or `WORLD` plus the active multiplier.
- `/journey speed 8` is the backwards-compatible short form for `MACHINES 8x`.
- restarting the server session resets speed to `MACHINES 1x`.

## Regression smoke

- `/journey botania debug tool` still reads Mana Pool values.
- Journey retrieval and Shift+right-click inventory fill still work.
- automatic Journey backups continue without the old long staging freeze.
