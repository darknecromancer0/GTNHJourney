# GTNH Journey 1.1.10 live test

Target: GTNH 2.9.0-beta-2, IC2 2.2.828-experimental.

1. Back up the world and replace Journey 1.1.9 with 1.1.10.
2. Load a world whose Journey research already contains `IC2:itemBatREDischarged` from 1.1.9.
3. Open Journey or make a diagnostic dump. The researched RE-Battery must resolve as `IC2:itemBatRE`, not `IC2:itemBatREDischarged`.
4. Retrieve that RE-Battery from Journey. Its tooltip should show the normal rechargeable capacity, `0 / 10 k EU`, rather than `0 / 0 EU`.
5. Put the retrieved battery into a normal IC2/GT charging path and verify that stored EU increases.
6. Craft or otherwise obtain another discharged RE-Battery. Journey must keep the same rechargeable `IC2:itemBatRE` identity instead of unlocking the non-electric placeholder again.
7. Save, exit, and restart the world. Verify the Journey entry is still `IC2:itemBatRE` and the retrieved battery is still rechargeable.
8. Re-check ordinary IC2 electric items already covered by charge endpoint normalization to catch regressions outside RE-Battery.
