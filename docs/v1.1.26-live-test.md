# GTNH Journey 1.1.26 Live Regression Checklist

Target: GT New Horizons 2.9.0-beta-2 / NEI 2.8.111-GTNH.

## Header and native NEI view

- Open a GUI and do not type into Search: the core `NEI J F C D` strip appears immediately once NEI's previous-page anchor exists. Search input must never be required to wake the Journey header up.
- Header shows `NEI J F C D` in the left Journey view zone, with `L Group Order` right-anchored clear of the native page number and page arrows.
- Every visible Journey header control, including the compact Group/Order root buttons and S/T, renders above NEI item cells even when their rectangles overlap an item slot.
- `S` (inventory scan) and `T` (Debug Researcher Tool) sit at the far right beside native `G` where room permits.
- On a narrower GUI, S/T disappear before any core view/sort button overlaps native G or the native page indicator.
- NEI is a slightly wider button and selects the ordinary native NEI content view.
- Open Group/Order dropdowns render above NEI item cells, never underneath them.
- Selecting a dropdown option must not also issue/click the NEI item geometrically underneath the popup.
- Header controls including L must own their click reliably and must not leave an NEI item-panel mouse-down active for mouse-up.
- In NEI with Group=None, Order=None, L=off, ordinary NEI owns the panel and native item-click behavior is unchanged.
- Enable any NEI Group/Order/L setting. The list reorders, but native NEI click/recipe/usage/cheat semantics remain unchanged.
- Switching NEI -> J -> NEI restores the sort combination previously chosen for NEI.

## C / Creative issuance

- Leave native NEI cheat mode disabled, select C, and LMB an unresearched native item. One item is issued anyway.
- RMB an unresearched stackable native item. One natural stack is issued.
- Shift+RMB an unresearched native item with several empty main-inventory slots. Every empty main slot is filled with a natural stack.
- Repeat with a researched exact Journey variant shown in C. It still uses normal Journey retrieval semantics.
- Issuing a valid unresearched exact identity from C immediately researches that exact issued identity and adds it to J through the normal authoritative unlock/sync path. No later inventory interaction is required.
- C issuance updates L/presentation activity only after an item is actually issued.
- On a dedicated server, a non-OP player cannot use C issuance; the integrated-server owner or an OP can.

## Galacticraft rocket fuel endpoints

- For the same Tier 1 rocket metadata, acquire/scan a rocket with no `RocketFuel` tag and one with `RocketFuel=0`: Journey shows one EMPTY state.
- Acquire/scan Tier 1 rockets with partial fuel and full fuel: Journey shows one FULL state, not one entry per fuel amount.
- Retrieving the FULL Tier 1 state returns a rocket at the actual configured full tank, including GTNH's `rocketFuelFactor`.
- Repeat EMPTY/FULL checks for Tier 2 and Tier 3 rockets.
- Functional rocket metadata variants remain distinct; only fuel amount is collapsed.
- Load an older world containing partial rocket states such as Tier 1 `3985` and `5000`: after migration only the canonical FULL state remains.

## Group / Order / Latest combinations

- J + L: pure latest activity across individual researched states. No stale N/group ordering may remain.
- J + N: all variants of a native family remain adjacent in native NEI order.
- J + N + L: issue a Fluid Cell variant from page 2+. The entire Fluid Cell family moves as one group; the issued/latest member is first, then the remaining family members retain native NEI order relative to one another.
- C + N + L: issue an item such as a specific Fluid Cell or block state. The exact issued identity becomes the first member of its moved group, followed immediately by the rest of that group.
- The issue above must NOT return the panel to page 1. The current page is retained unless it no longer exists.
- From J + N + L choose Group=None. Output immediately becomes pure J + L with no residual native-family influence.
- J + N + U: learning one new Fluid Cell subtype moves the whole family according to the newest learned member while preserving native family order when L is off.
- J + N + U + L: latest activity is primary, unlock time secondary for group priority; the latest member is promoted to the head of its active family.
- M/T/K group modes keep members in stable groups; with L enabled the latest member is promoted to the group head while all remaining members keep their deterministic relative order.
- F+ is offered only in F and orders favourites by most recent explicit addition.
- Adding an already-favourited item from J is idempotent and does not make it newer in F+.
- Remove an item from F with Alt+RMB, then re-add it from J with Alt+LMB: it becomes the newest F+ entry.

## GTNH NEI filtering parity

Test every view that has content: NEI, J, F, C, D.

- Item Subsets is applied before Journey sorting.
- Select Avaritia through Item Subsets. No GregTech/Thaumcraft item may reappear because of N/M/T/K/U/A/L.
- Search with native prefixes/operators including `@`, `%`, `#` and the other operators configured by the installed GTNH NEI build.
- Sorting may only reorder surviving results. It must never reintroduce an item filtered out by SearchField or Item Subsets.
- Journey-only exact variants still display/retrieve as their exact state while using the correct native representative for subset/family membership.

## `empty` fluid-container search

- Search literal `empty` in ordinary NEI and Journey views.
- Empty Fluid Cell and genuinely empty Steel/Titanium/etc. fluid containers are shown even when their display name does not literally contain `Empty`.
- Water/Steam/Oxygen/other filled Fluid Cells do not appear solely because hidden tooltip/search data contains `empty`.
- A filled container whose actual visible display name itself contains `Empty` may still match normally.
- Prefix searches such as `@empty`, `%empty`, `#empty` are not rewritten by Journey and retain native GTNH NEI behavior.

## Command popup navigation

- Type a slash command with completion candidates.
- Plain Up/Down navigates ordinary Minecraft chat/command history and is never consumed by Journey.
- Shift+Up / Shift+Down moves the popup selection.
- Tab accepts the selected popup suggestion.
- With no popup visible, Shift+Up/Down is not consumed.
- Test at least one vanilla command, one Journey command and one command from another GTNH mod.

## Ctrl+Backspace search safety

- Open a GUI with the lower NEI search field focused.
- Type multiple words and press Ctrl+Backspace repeatedly.
- The search field deletes words normally.
- The containing GUI must not close and unrelated global/mod keybindings must not fire from the same Backspace event.
- Plain Backspace still behaves normally.
- Ctrl+Backspace outside the focused NEI search field remains available to ordinary Minecraft/mod key handling.

## Existing 1.1.25 regressions

- J/F/C issue semantics remain: LMB=1, RMB=natural stack, Shift+RMB=fill main inventory.
- Alt+LMB adds to F only from J; Alt+RMB removes only inside F.
- Debug Researcher Tool, spawner identity, death inventory guard, external snapshot recovery, safe machine speed and explosion controls remain functional.
