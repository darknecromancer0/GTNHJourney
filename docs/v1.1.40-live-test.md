# GTNH Journey 1.1.40 live test

Target: GTNH 2.9.0-beta-2, NEI 2.8.111-GTNH.

## Ctrl+Backspace focus
1. Open an inventory/NEI screen and focus the main search field.
2. Type several words.
3. Press Ctrl+Backspace repeatedly, including while key repeat is active.
4. Immediately continue typing without clicking anywhere.
5. The field must keep focus and accept text every time; recipe history/back navigation must not trigger and the GUI must not close/crash.

## Duplicate migration
After replacing 1.1.39 with 1.1.40, fully restart/load the world and open Journey.

Expected:
- vanilla sword/bow/armor/tool entries differing only by `ench` collapse to their base item; custom display/name/color remains distinct
- Tainted Villager Soul Vials with quoted-empty names and per-entity runtime data collapse to one Tainted Villager vial
- ordinary legacy `ExtraUtilities:unstableingot:0` BASE and `crafting=true` collapse to the dangerous crafted semantic state
- Portable Scanner keeps only charge endpoints; cached scan/pollution lines are removed
- Item Dislocator `ConfigProfiles` variants collapse
- Biomes O' Plenty invalid hive meta 9 migrates to Honeycomb Block meta 0; real metas 1/2/3 remain distinct
- Field Engineer's Toolbox open/empty-content wrappers collapse
- Electric Prospector's Scanner `DetravData` mode variants collapse while normal 0/100 charge endpoints remain
- EnderIO Wireless Charger stored-energy snapshots collapse; capacitor-bank energy is ignored while face configuration remains distinct
- Enhanced LootBag glint/RepairCost duplicates collapse
- default Railcraft tank `color=15` copies collapse
- disabled Talisman of Remedium wrapper collapses

Do not expect different fluid contents, mob types, Forestry genetics, Thaumcraft aspects/research notes, encoded AE patterns, terminal bindings/modes, or custom-named gear to merge.
