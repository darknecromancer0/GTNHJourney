# GTNH Journey 1.1.26 Creative and Rocket-State Fix Plan

**Goal:** Restore C / Creative issuance independently of native NEI cheat mode and collapse Galacticraft rocket fuel into exactly EMPTY/FULL Journey states while preserving functional rocket variants.

## Creative issuance

1. Add regression tests proving C routes unresearched items to a Journey server request and never gates issuance through `NEIClientConfig.canCheatItem`.
2. Reuse `JourneyAdminPermissionPolicy`: integrated-server owner or operator only.
3. Add bounded client -> server creative issue request carrying one exact `ItemStack`, requested amount, and fill-inventory intent.
4. Validate permission, stack validity, wire-size budget, and amount server-side before issuing.
5. Reuse `MainInventoryFillService` for Shift+RMB.
6. Send a success acknowledgement only after at least one item is actually issued. The client then touches `ClientPresentationActivityMirror`; failed issuance must not affect L/activity.
7. Researched C states continue through normal authoritative Journey retrieval and never become newly researched through C.

## Galacticraft rocket fuel states

1. Add `GalacticraftRocketFuelStatePolicy` for the verified GTNH Galacticraft rocket items:
   - `GalacticraftCore:item.spaceship`, base tank 1000;
   - `GalacticraftMars:item.spaceshipTier2`, base tank 1500;
   - `GalacticraftMars:item.itemTier3Rocket`, base tank 1500.
2. Resolve FULL as `baseTank * ConfigManagerCore.rocketFuelFactor` at runtime, with a fail-safe factor of 1 only if Galacticraft configuration cannot be read.
3. Preserve metadata and all non-fuel NBT. Only `RocketFuel` is normalized.
4. Missing/zero/negative `RocketFuel` => EMPTY and the fuel tag is removed.
5. Any positive `RocketFuel` => FULL and the stored/retrieved template is rewritten to the actual configured capacity.
6. Apply the same policy to research identity, retrieval templates, and persisted-entry migration so old partial variants deduplicate on load.
7. Unknown items that merely contain a `RocketFuel` tag remain exact/fail-closed.
