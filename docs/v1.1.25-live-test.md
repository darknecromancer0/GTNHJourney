# GTNH Journey 1.1.25 Final Live Test

Target: GTNH 2.9.0-beta-2 / NEI 2.8.111-GTNH.

## Global command hints

1. Open chat and type `/jour` without pressing Tab. The suggestion popup must appear while typing.
2. Type `/journey ` and verify Journey subcommands appear.
3. Type another registered non-Journey command prefix such as `/gam` and verify server commands are suggested too.
4. With several suggestions visible, use Down/Up. The highlighted row must move and stay visible even in lists longer than 10 entries.
5. Press Tab. The highlighted current token must be inserted without executing the command.
6. Close/reopen chat and reconnect once. Old suggestions must not leak into the next session.
7. With no suggestion popup, Up/Down must retain vanilla chat-history behaviour.

## Journey command errors and help

- `/journey wat` must use a red scoped command error, not dump the full help page.
- `/journey explosions ogf` must suggest the explosion branch only.
- `/journey explosions machines wat` must suggest `status|on|off`.
- `/journey speed machines 32` must be rejected as unsafe before changing speed.
- `/journey help` must include speed default/undo/redo, explosion machines/default/undo/redo, death inventory recovery and external snapshot return.

## NEI / Journey UI regression

- In J, select Item Subsets -> Mod -> Avaritia. Only entries belonging to that native NEI subset should remain. GregTech/Thaumcraft leakage must not occur.
- Check native search prefixes such as `@`, `#`, `%`, `$`, `&` in J and compare with ordinary NEI.
- Go to page 2+ in J/N/F/C and issue an item. The page must remain the same unless the active filter itself changes the number of available pages below that page.
- J/N: Alt+LMB adds to F without issuing an item on that click. Repeating is an idempotent no-op.
- F: Alt+RMB removes from F without issuing an item on that click.
- J/N/F/C: ordinary LMB gives 1, RMB gives one natural stack, Shift+RMB fills available main-inventory slots.
- C contains native NEI entries plus missing exact Journey variants grouped next to their native item/meta family.

## Debug Researcher Tool

- Hold Shift and keep RMB physically held. The mode must advance only once. Release and press again to advance one more mode.
- BLOCK on a Silverfish spawner must research a Silverfish spawner, never a Pig fallback and never a second `no target` action.
- AREA_16 must also discover the spawner and dropped EntityItem stacks with exact metadata/NBT.

## Recovery and safety

- With keepInventory enabled, perform a controlled death while wearing Baubles. If GTNH loses anything, Journey must warn and `/journey return death inventory` must return only missing contents.
- `/journey undo` / `/journey redo` and category-specific undo/redo should reverse the latest supported research/admin action in order.
- `speed machines` is limited to 16x. Test a real EBF + battery/buffer/cable chain at 16x and confirm processing and EU flow stay in lockstep.
- `speed world 32/64/128` remains separate and may be used when supported.
- Verify external snapshots are under `<instance>/gtnhjourney-recovery/<world>/research-snapshots/`, outside `saves/`.
- After loading an older world backup, `/journey snapshot latest return` should restore the newest valid external Journey research snapshot without overwriting the live player inventory.
